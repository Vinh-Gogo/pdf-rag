# Update Memory Bank

1. **Review Current State**
   - Read `.agent/memory/context.md` to see previous state
   - Scan recent changes in the codebase (git log or recent edits)

2. **Update Context**
   - Update `.agent/memory/context.md` with latest achievements
   - Add new "Next Steps" based on current progress

3. **Check for Architectural Changes**
   - If new modules or patterns were added, update `.agent/memory/architecture.md`

4. **Update Tech Stack**
   - If new dependencies were added, update `.agent/memory/tech-stack.md`

5. **Document New Patterns**
   - If a new repetitive task was performed (e.g. testing pipeline), add to `.agent/memory/patterns/common-tasks.md`

6. **Confirm Update**
   - Notify user that memory bank has been updated
